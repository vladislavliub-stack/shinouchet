## Живые данные

Не хранить в GitHub реальные номера машин, заметки, записи, историю изменений или пользователей. Репозиторий публичный.

Для миграции нужны: `public.work_members`, `public.work_visits` (включая `comments`, `history`, `deleted_at`) и `auth.users`/настройка локальной авторизации. На 12 ноября 2026 года проверены 17 записей, 2 участника, 29 событий истории, 0 комментариев, 0 записей в корзине.

Текущие данные доступны через Supabase только на чтение. Полноценный архив со схемой, данными и авторизацией пока не создан. Перед переключением нужен приватный pg_dump и проверка восстановления на отдельном сервере.

Не коммитить ключи API, пароль базы и cookies.
